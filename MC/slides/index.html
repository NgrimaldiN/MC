Part 0 - Article

Zero variance Markov chain Monte Carlo for Bayesian estimators

A. Mira, R. Solgi and D. Imparato, Statistics and Computing, 2013.

Question of the paper

How can we reduce the Monte Carlo error of posterior averages without changing the target distribution?

Main tool

\[ \widetilde f(x)=f(x)+a^\top z(x), \qquad z(x)=-\frac12\nabla\log\pi(x) \]

  • The correction has expectation zero under the posterior.
  • The coefficient \(a\) is estimated by regression on MCMC draws.
  • Our example: Bayesian estimation of a GARCH(1,1) model.
Say that the paper is general. The GARCH model is the numerical example we use.
Question 1

Implement a random-walk Metropolis sampler for the GARCH posterior

Use simulated data first, then real log-returns computed from exchange rates.

Q1 - model

We simulate from the same GARCH recursion

def simulate_garch(w1, w2, w3, T=3000):
    r = np.zeros(T)
    h = np.zeros(T)
    h[0] = w1 / (1 - w2 - w3)

    for t in range(1, T):
        h[t] = w1 + w3 * h[t-1] + w2 * r[t-1]**2
        r[t] = rng.normal(0, np.sqrt(h[t]))

    return r, h

Starting from the unconditional variance avoids an artificial warm-up in the simulated series.

Q1 - sampler

Random-walk Metropolis in the constrained parameter space

proposal_w = current_w + rng.normal(0, step_sizes, 3)
proposal_lp = log_prior(proposal_w)

if proposal_lp > -np.inf:
    proposal_ll = log_likelihood(proposal_w, r)
    log_ratio = (proposal_ll + proposal_lp) - (current_ll + current_lp)

    if np.log(rng.random()) < log_ratio:
        current_w = proposal_w

Acceptance rates in the final notebook: about 25% on simulated data and 36% on real data.

Question 2

Use the first-order control variate from the paper

Explain how \(f(x)+a^\top z(x)\) is used through a linear regression.

Q2 - score

The control variate needs the gradient of the log-posterior

term = 0.5 * (r[t]**2 / h[t] - 1.0) / h[t]

dh[t, 0] = 1.0 + w3 * dh[t-1, 0]
dh[t, 1] = r[t-1]**2 + w3 * dh[t-1, 1]
dh[t, 2] = h[t-1] + w3 * dh[t-1, 2]

grad_ll += term * dh[t]

\[ z(w)=-\frac12\nabla \log \pi(w\mid r) \]

Q3 - LSLASSO

We screen variables by Lasso, then refit OLS

lasso = LassoCV(cv=5).fit(X_design, Y)
active_vars = np.where(lasso.coef_ != 0)[0]

if len(active_vars) > 0:
    ols = LinearRegression().fit(X_design[:, active_vars], Y)
    estimate = ols.intercept_
else:
    estimate = np.mean(Y)

Question 4

Is ordinary linear regression valid on an MCMC sample?

Think about dependence, and possible fixes such as thinning or block averages.

Q4 - issue

The regression rows are not iid

Consecutive Metropolis-Hastings draws are autocorrelated. So the OLS coefficient can be useful, but iid regression standard errors are not the right error assessment.

\[ n_{\mathrm{eff}} \approx \frac{n}{1+2\sum_{k\ge 1}\rho_k} \]

  • Use repeated independent chains for boxplots.
  • Use batch means for standard errors.
  • Fit regression on thinned samples or block averages.
Q4 - check

Thinning and block means reduce visible dependence

This is our practical answer: keep the control variate, but assess error with MCMC-aware diagnostics.

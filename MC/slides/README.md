# Reveal.js slides

This folder contains the oral-presentation deck.

Run locally from `MC/slides`:

```powershell
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```

Speaker view:

```text
Press S
```

PDF export:

```text
http://localhost:8000/?print-pdf
```

Then print from Chrome/Chromium with:

- Layout: Landscape
- Margins: None
- Background graphics: enabled

Reveal.js references used:

- Markup hierarchy: https://revealjs.com/markup/
- Speaker notes: https://revealjs.com/speaker-view/
- Math plugin: https://revealjs.com/math/
- PDF export: https://revealjs.com/pdf-export/
